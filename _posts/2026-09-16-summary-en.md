### [Capsule packs web apps and SQLite data into one file](https://withcapsule.app/) ⭐️ 7.0/10

Capsule is a Rust/Tauri 2.0 tool from bashtian that packs an HTML web app and its SQLite data into a single-file application with a .capsule extension. The HTML file and related assets are embedded directly in the database; user data can be stored as localStorage key/value pairs or as documents via a MongoDB-inspired collections API in a table, while PDFs and images can also be saved in the database and exported to CSV or JSON. For privacy and security, documents have no file-system access and need permission to reach the internet, the permission model is still being improved, and documents can use local or remote AI models for document-specific AI features. Since collaborators create separate copies, each data entry carries a UUID and timestamp for merging, and the author plans to open the file format specification for version 1.0 so other apps can read or write Capsule files; migrations are in place for future versions to prevent data loss.

hackernews · bashtian · Sep 15, 13:31 · [Discussion](https://news.ycombinator.com/item?id=49712278)

**「Background」** Tauri 2.0 is an open-source application framework designed to create cross-platform desktop and mobile applications on Linux, macOS, Windows, Android, and iOS, using a JavaScript frontend and Rust application logic. SQLite has a long history as an application file format because an ordinary SQLite database is a single, cross-platform file with a stable format that supports transactional updates and high-level queries. The File System Access API, meanwhile, allows web pages to read and write files on a user&\#x27;s local device, which is the browser-native alternative discussed by commenters.

**「Impact」** The concrete consequence is that developers can hand someone a single file containing both an HTML app and its SQLite data, but the lack of built-in sync and app/data separation means multi-device or collaborative use still depends on manual copy merging.

**「Community discussion」** HN commenters compared Capsule to SQLite executable packaging and the File System Access API, and thederf said they are building a similar sqlar-based project that works in browsers and on desktop and Android with Tauri. Others praised the ease of sharing small AI-built local tools but cited missing cross-device sync, app/data separation, app updates, and runtime installation, and nater5000 questioned whether the approach generalizes beyond specific use cases.
