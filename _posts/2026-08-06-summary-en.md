### [ChainDrop Worm Compromises 1,300+ npm Packages](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 8.0/10

The self-propagating ChainDrop worm has compromised more than 1,300 npm packages with roughly 2 billion combined monthly downloads, including popular cache libraries Keyv and Cacheable. The attack began after a Keyv maintainer&\#x27;s GitHub account was breached and spread to packages associated with organizations including Deliveroo, Qlik, and ServiceTitan. Malicious versions were published through a legitimate GitHub Actions workflow, so they carried valid provenance. The poison packages&\#x27; setup.mjs dropper and Math\_Symbol.js credential stealer run automatically during npm install, harvesting GitHub, npm, AWS, and Kubernetes credentials while infecting other maintainers&\#x27; packages. Security guidance says affected installations should be treated as compromised: rebuild environments, rotate all tokens, and inspect logs, with npm-cache\[.\]com as an indicator of compromise; the incident is still spreading and more affected packages are expected.

telegram · zaihuapd · Aug 5, 03:04

**「Background」** npm is the primary package registry for Node.js and a major vector for software supply-chain attacks because developers often install dependencies automatically during builds. In this case, using the compromised maintainer&\#x27;s normal GitHub Actions release pipeline made the malicious updates appear legitimate, and valid npm provenance made them even harder to distinguish from routine releases.

**「Impact」** Developers and organizations that installed any affected version should assume their systems and credentials are exposed and immediately rebuild environments, rotate tokens, and audit logs for signs of follow-on compromise.

### [ByteDance launches SeedRealtime for native full-duplex audio-video dialogue in Doubao](https://seed.bytedance.com/zh/blog/seedrealtime-%E9%9F%B3%E8%A7%86%E9%A2%91%E5%85%A8%E5%8F%8C%E5%B7%A5%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%8F%91%E5%B8%83-%E8%B5%B0%E5%90%91%E5%85%A8%E6%A8%A1%E6%80%81%E8%87%AA%E7%84%B6%E4%BA%A4%E4%BA%92) ⭐️ 8.0/10

On August 5, ByteDance released SeedRealtime, a native audio-video full-duplex model that is now fully deployed in the Doubao app. The model uses a unified architecture that fuses audio, video, and text, enabling real-time interaction across a continuous multimodal stream with audio-video joint understanding, proactive environmental awareness, and smooth conversational pacing. In end-to-end human evaluations, SeedRealtime halved audio-video dialogue pacing problems compared with cascaded models, with significant reductions in interruptions such as users being cut off mid-speech. Unlike traditional cascaded systems that rely on sequential ASR, VLM, and TTS modules, SeedRealtime integrates perception, understanding, decision-making, and expression in a single end-to-end model without requiring an external VAD for turn-taking, supporting natural full-duplex interaction that can see, listen, and speak simultaneously.

telegram · zaihuapd · Aug 5, 04:42

### [Monodratic: Sparse Causal Attention via Learned Product-Hash Routing](https://www.reddit.com/r/MachineLearning/comments/1vg3jda/monodratic_learned_producthash_routing_for_sparse/) ⭐️ 7.0/10

Monodratic is a sparse causal-attention architecture that uses learned product-hash routing to assign source blocks to bounded posting lists after RoPE, while each query probes product addresses, reranks candidates, selects a fixed number of remote blocks, and runs exact causal softmax over those tokens plus guaranteed local blocks. In synthetic associative-recall tests, learned routing with 2 selected remote blocks out of 5 eligible achieved 763/768 correct answers across three seeds \(99.35% mean, 98.05% minimum\), versus 425/768 for an equally wide untrained router and 151/768 for local-only attention. Forcing the labelled target block while keeping the same maximum attention budget recovered all remaining errors, reaching 768/768, and sparse selected-set attention agreed with an independent dense selected-mask oracle to a maximum absolute error of 1.43e-6. The packed CPU routing implementation showed a fitted timing exponent of 0.993 from 4,096 to 32,768 tokens under the fixed balanced configuration, with zero posting overflow reported in all learned-route and scaling runs. The work is limited to synthetic experiments, uses portable PyTorch rather than a fused kernel, and does not claim natural-language quality, asymptotic linear construction, or deployment speed.

reddit · r/MachineLearning · /u/dttdrv · Aug 5, 10:28

**「Background」** Causal attention restricts each query to previous tokens, which becomes computationally expensive as sequence length grows, motivating sparse attention techniques that route each query to a subset of keys. Product hashing builds on this idea by assigning source blocks to posting lists using hash functions and letting each query probe a bounded set of address combinations, then reranking candidates. Associative recall is a task that tests whether a model can retrieve a linked key-value pair from earlier in a sequence, and it is a common failure point for naive sparse-attention methods.

**「Impact」** Monodratic&\#x27;s results suggest that learned product-hash routing can maintain strong associative recall while scaling near-linearly on synthetic sequences, which is relevant for researchers seeking efficient attention mechanisms. However, because the experiments are synthetic and the implementation is not a production kernel, real-world performance and deployment benefits remain unproven.
